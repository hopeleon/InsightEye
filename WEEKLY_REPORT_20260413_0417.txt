一、本周工作概述
--------------------------------------------------------------------------------
本周是 InsightEye 项目推进的关键一周，主要围绕"实时DISC分析"功能的
开发与集成展开，同时完成了声纹识别系统的搭建、WebSocket实时通信的
大规模重构、模型管理体系的完善、Docker容器化部署支持，以及前端界面的
全面改善。本周共完成 8 次提交，新增/修改文件约 38 个，代码净增
+8,681 行。

【1】实时DISC分析模块（核心功能，299行新增代码）
    ├─ 新增 app/realtime_disc_analyzer.py
    │   - 高频实时DISC分析引擎，支持流式推理
    │   - 集成DISC四大维度（D支配/I影响/S稳定/C谨慎）的实时计算

    │
    ├─ 新增 prompts/realtime_disc_prompt.txt
    │   - DISC分析专用提示词模板

    │
    └─ 修改 app/realtime_session.py
        - 新增DISC会话状态管理
        - 支持会话上下文记忆与跨轮次分析
        - 集成DISC分析结果的缓存与检索机制


【2】声纹识别系统（全新模块，1,601行新增代码）
    ├─ 新增 app/speaker_recognition.py
    │   - 声纹特征提取（基于campplus模型）

    │   - 支持中英文双语声纹识别
    │   - 提供声纹注册与更新接口
    │
    ├─ 新增 app/streaming_pipeline.py
    │   - 流式语音处理完整管线
    │   - 整合VAD语音活动检测 + ASR自动语音识别 + 声纹识别
    │   - 支持断句重传与增量解码
    │   - 多路并发音频流管理
    │
    ├─ 新增 app/vad_asr_pipeline.py
    │   - VAD语音活动检测模块
    │   - ASR自动语音识别管线
    │   - 时间戳对齐与文本同步输出
    │   - 噪声过滤与环境音自适应
    │
    ├─ 修改 app/speaker_recognition.py / app/streaming_pipeline.py
    │   - 实现声纹二选一强制逻辑
    │   - 当两个声纹阈值都未达标时，强制用户从两个候选声纹中选一
